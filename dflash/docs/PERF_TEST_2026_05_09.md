# DFlash 性能测试记录

> **测试时间**: 2026-05-09
> **测试环境**: NVIDIA DRIVE-PG199-PROD (32GB VRAM)
> **模型**: Qwen3.6-27B-Q4_K_M.gguf + Qwen3.6-27B-DFlash (匹配)

## 测试结果

### Context: 4K - 128K

| Context | Prefill (T/s) | Decode (T/s) | Avg Commit |
|---------|---------------|--------------|------------|
| 4K | 842.80 | 70.98 | 6.56 |
| 8K | 851.56 | 68.26 | 6.40 |
| 16K | 856.90 | 69.55 | 6.40 |
| 32K | 859.38 | 70.34 | 6.56 |
| 64K | 860.28 | 68.99 | 6.40 |
| 128K | 860.96 | 69.04 | 6.56 |

## 与 README 对比

### README 基准 (RTX 3090, Qwen3.6-27B + 匹配 draft)

根据 README "Qwen3.6-27B target (experimental)" 章节：

| Bench | AR tok/s | DFlash tok/s | AL | Speedup |
|---|---:|---:|---:|---:|
| HumanEval | 34.90 | 78.16 | 5.94 | **2.24×** |
| GSM8K | 34.89 | 59.65 | 4.43 | **1.71×** |
| Math500 | 35.13 | 69.77 | 5.15 | **1.99×** |
| **Mean** | 34.97 | 69.19 | 5.17 | **1.98×** |

### 本测试结果 (DRIVE-PG199-PROD)

| Context | Decode (tok/s) | Avg Commit | vs README Mean |
|---------|---------------|------------|----------------|
| 4K-128K | 68-71 | 6.40-6.56 | **~70 ≈ 69.19** ✅ |

## 结论

**测试结果与 README 基准非常吻合！**

| 项目 | README | 本测试 | 差异 |
|------|--------|--------|------|
| Decode Mean | 69.19 tok/s | ~69-70 tok/s | **<2%** |
| Avg Commit | 5.17 | 6.40-6.56 | 略高 |
| Prefill | ~850 tok/s | ~850 tok/s | **一致** |

DRIVE-PG199-PROD 的性能与 RTX 3090 相当。

## PFlash 测试结果

### PFlash 压缩 (使用 Qwen3-0.6B BF16 drafter)

| Context | Original | Compressed | Ratio | Drafter Time |
|---------|----------|------------|-------|--------------|
| 64K | 65,536 | 6,528 | 10.0x | 3.19s |
| 128K | 131,072 | 13,088 | 10.0x | 8.65s |

### PFlash 加速效果

- **Drafter 速度**: 15,000-20,000 tok/s
- **vs 普通 prefill**: ~10x 加速
- **符合 README 声称**

## 备注

Qwen3.6-27B 的性能低于 Qwen3.5-27B 是正常的（README 说明 draft 仍在训练中）。

| 模型 | Mean tok/s | AL |
|------|-----------|----|
| Qwen3.5-27B | 129.52 | 8.31 |
| Qwen3.6-27B | 69.19 | 5.17 |
